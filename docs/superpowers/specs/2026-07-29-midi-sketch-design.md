# MIDI Sketch — 디자인 스펙

날짜: 2026-07-29
상태: 사용자 승인 대기

## 목적

Logic Pro 인터페이스가 어려운 사용자가 **곡 전체(멜로디+코드+베이스+드럼)를 간단하게 스케치**하고, 결과를 **표준 MIDI 파일(.mid)로 내보내 Logic Pro에 드래그**해서 이어서 작업할 수 있는 로컬 웹앱.

핵심 사용자 특성:
- 화성(코드) 지식이 부족함 → **불협을 피하도록 앱이 안내**해야 함
- 드럼을 직접 찍지 못함 → **드럼은 선택+자동 생성** 방식
- 주 장르: **Rock / Alternative / J-Rock**

## 구현 형태

- 로컬 웹앱 (브라우저 실행, 설치 불필요)
- Vite + vite-plugin-singlefile로 **단일 HTML 파일로 빌드** → 더블클릭으로 실행
- 프레임워크: Svelte (반응형 그리드 UI에 적합, 번들 작음)
- 소리 재생: Web Audio API 내장 신디사이저 (기타/베이스/리드/드럼 합성음 — 스케치 확인용 품질이면 충분)
- 저장: localStorage 자동 저장 + JSON 파일 내보내기/불러오기
- UI 언어: 한국어

## 화면 구성 (승인된 목업 기준)

### 상단 바
- 곡 제목, 키 선택(장조/단조 전체), 템포(BPM), 재생/정지, MIDI 내보내기, 프로젝트 저장/불러오기

### 곡 배치 레인
- 섹션(인트로, A멜, B멜, 사비 등)을 블록으로 생성·복제·삭제
- 드래그로 순서 배치, 같은 섹션 여러 번 배치 가능
- 섹션 수정 시 배치된 모든 위치에 반영

### 섹션 편집기
섹션 = 마디 수(기본 4/8마디) + 아래 레인들:

**코드 레인**
- 마디당 1개 기본, 반마디 분할 가능
- 코드 선택 UI 2탭:
  - 추천 탭: 현재 키의 다이어토닉 코드 + 록 상용 진행 원클릭 적용 (예: i–VI–III–VII, I–V–vi–IV 등)
  - 직접 만들기 탭: 루트(12음) × 종류(메이저/마이너/7/m7/maj7/sus4/add9/파워5/dim) × 분수코드 베이스음
- 코드 미리 듣기, 키와 어울리는 코드에 ★ 표시 (어울리지 않아도 선택은 허용)

**기타 레인 / 베이스 레인**
- 마디마다 패턴 프리셋 선택 (파워코드 8비트, 뮤트 스타카토, 아르페지오, 스트로크 등 / 베이스: 루트 8비트, 옥타브, 워킹 등)
- 프리셋을 16분음표 스텝 편집기로 커스텀 가능 (온/오프 + 세게/약하게 2단계 벨로시티)
- 커스텀 패턴 이름 붙여 저장 → 다른 마디/섹션에서 재사용
- 패턴은 코드 레인의 현재 코드를 따라 음이 자동 결정됨

**드럼 레인 (자동 생성 중심)**
- 스타일 선택: 록 8비트, 록 16비트, 하프타임, 펑크 질주, 탐 그루브 (각각 미리 듣기)
- 조절: 에너지 슬라이더(잔잔↔강렬), 필인 자동(섹션 끝 탐 굴리기), 크래시 자동(섹션 시작)
- 생성 결과를 스텝 그리드로 표시 (크래시/하이햇/스네어/하이탐/플로어탐/킥 레인) — 칸 클릭 미세 수정은 옵션, 필수 아님

**멜로디 그리드**
- 피아노롤 단순화판: 세로 음높이(2옥타브 스크롤), 가로 16분음표, 클릭으로 찍기, 드래그로 길이 조절
- **화성 가이드 색상** (핵심 기능):
  - 밝은 배경 = 현재 마디 코드의 구성음 (잘 어울림)
  - 중간 배경 = 키 스케일 음 (무난)
  - 어두운 배경 = 스케일 밖 (불협 주의 — 찍는 것은 허용)
- 코드가 바뀌면 색상도 마디별로 따라 바뀜

## 아키텍처

단일 페이지 앱, 모듈 분리:

- `model/` — 곡 데이터 모델 + localStorage 저장/불러오기
- `theory/` — 음악 이론 엔진: 스케일 생성, 코드 구성음 계산, 다이어토닉 코드 추천, 음 분류(코드톤/스케일/밖)
- `patterns/` — 패턴 정의(내장 프리셋 + 커스텀) 및 "패턴 × 코드 → 노트 목록" 변환
- `drums/` — 드럼 생성기: 스타일 × 에너지 × 필인 설정 → 드럼 노트 목록
- `render/` — 곡 배치 전체를 노트 이벤트 타임라인으로 펼치는 공통 렌더러 (재생과 MIDI 내보내기가 공유)
- `audio/` — Web Audio 재생 (신스 음색, 스케줄러)
- `midi/` — 표준 MIDI 파일(SMF format 1) 작성기
- `ui/` — Svelte 컴포넌트 (상단 바, 곡 배치, 섹션 편집기, 멜로디 그리드)

데이터 흐름: UI 편집 → 곡 모델 갱신 → (재생 시) render → audio / (내보내기 시) render → midi.

## 데이터 모델 (요약)

```
Song { title, key: {root, mode}, bpm, sections: Section[], arrangement: sectionId[] }
Section { id, name, color, bars, chords: ChordSlot[], guitar: PatternRef[], bass: PatternRef[],
          drums: DrumConfig, melody: Note[] }
ChordSlot { position(반마디 단위), root, quality, bassNote? }
PatternRef { presetId | customId }  // 마디당 1개
CustomPattern { id, name, track, steps: (0|1|2)[16] }  // 2=세게
DrumConfig { style, energy(0..1), autoFill: bool, autoCrash: bool, overrides: {lane, step, value}[] }
Note { pitch, startStep, lengthSteps }
```

## MIDI 내보내기

- SMF Format 1, 4개 트랙: 멜로디 / 기타 / 베이스 / 드럼(채널 10, GM 드럼맵: 킥36 스네어38 하이햇42 하이탐48 플로어탐41 크래시49)
- 템포·박자·키 시그니처 메타 이벤트 포함, 트랙 이름 한글 대신 영문(호환성)
- 벨로시티: 세게 100 / 약하게 70 (Logic에서 다듬기 좋은 중간값)
- 파일명: `곡제목.mid` 다운로드 → Logic에 드래그하면 트랙별로 임포트됨

## 에러 처리·엣지 케이스

- 코드 없는 마디: 직전 코드 유지, 곡 시작부터 없으면 기타/베이스 무음 + 안내 표시
- 빈 섹션/빈 배치: 재생·내보내기 버튼 비활성 + 이유 툴팁
- localStorage 자동 저장(편집 시 디바운스), 새로고침 복원
- 대상 브라우저: Safari + Chrome 최신 (Mac)

## 테스트

- 단위 테스트(Vitest): theory(스케일/코드/분류), patterns(코드 적용 변환), drums(생성 규칙), midi(바이트 출력 스냅샷 + 헤더/이벤트 검증)
- 수동 검증: 재생 소리 확인, 내보낸 .mid를 Logic Pro에서 임포트해 트랙·음·템포 확인 (사용자와 함께)

## 성공 기준

1. 코드 지식 없이 색상 가이드만 보고 불협 없는 멜로디를 찍을 수 있다
2. 드럼을 한 칸도 직접 찍지 않고 자연스러운 록 드럼(탐 필인 포함)이 나온다
3. 섹션 배치로 3분 분량 곡 뼈대를 30분 내에 만들 수 있다
4. 내보낸 .mid가 Logic Pro에서 트랙별로 정상 임포트된다

## 범위 제외 (YAGNI)

- Logic 실시간 연동(Web MIDI), 오디오 녹음, 가사, 고품질 음원, 모바일 지원, 3단계 이상 벨로시티, 박자 변경(4/4 고정)
